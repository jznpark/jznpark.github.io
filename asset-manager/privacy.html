1. 요약

  • 이 앱은 개발자가 운영하는 서버가 없습니다. 개발자는 사용자의 정보를 수집하거나 받아 보지 않습니다.
  • 입력한 자산 정보는 사용자의 기기 안에만 저장됩니다.
  • 시세와 종목 검색을 위해 종목코드와 검색어가 외부 시세 제공처로 전송됩니다. 보유 수량·금액·계좌 정보는 전송되지 않습니다.
  • 광고, 분석 도구, 로그인 기능이 없습니다.

2. 개발자가 수집하는 정보

없습니다. 앱은 개발자에게 어떤 정보도 보내지 않습니다.

3. 기기 안에만 저장되는 정보

아래 정보는 사용자가 입력하거나 앱이 계산해 기기의 앱 전용 저장 공간에 저장합니다. 외부로 전송하지 않습니다.

  • 소유자 이름(사용자가 붙인 호칭), 계좌별 보유 종목·수량·목표 비중, 예적금·채권 내역, 자산 기록(스냅샷), 재무 목표, 규칙서 설정
  • 환율·시세·시장 지표의 마지막 조회 값과 과거 시세 캐시
  • 앱 설정(테마, 표시 모드, 알림 사용 여부, 시세 갱신 주기 등)
  • 앱 잠금을 켠 경우 PIN의 해시값(PIN 원문은 저장하지 않습니다)
  • 공공데이터포털 인증키(데이터에 설정돼 있는 경우)

저장 위치는 앱 전용 폴더이며 다른 앱이 읽을 수 없습니다. 파일 자체를 별도로 암호화하지는 않습니다. 기기의 클라우드 백업에는 포함되지 않습니다.

생체 인증(지문·얼굴)은 기기의 운영체제가 처리합니다. 앱은 생체 정보를 받거나 저장하지 않고 인증 성공 여부만 전달받습니다.

4. 외부로 전송되는 정보

시세를 조회하거나 종목을 검색할 때 앱이 아래 제공처에 직접 요청을 보냅니다. 요청은 모두 HTTPS로 암호화됩니다.

제공처전송되는 내용시점
네이버 금융 (m.stock.naver.com, api.stock.naver.com, ac.finance.naver.com)국내 종목코드, 종목 검색어시세 갱신, 과거 시세 조회, 종목 검색
Yahoo Finance (query1.finance.yahoo.com)해외 종목 티커, 환율·지수 심볼, 종목 검색어시세·환율·지수 갱신, 과거 시세 조회, 종목 검색
공공데이터포털 (apis.data.go.kr)국내 종목코드, 사용자의 공공데이터포털 인증키인증키가 설정돼 있을 때의 국내 종가 조회
  • 인터넷 통신의 특성상 사용자의 IP 주소가 각 제공처에 전달됩니다.
  • 요청에는 일반적인 브라우저 형식의 User-Agent 문자열이 포함됩니다. 기기 식별자, 광고 ID, 계정 정보는 포함되지 않습니다.
  • 보유 수량, 평가 금액, 계좌 이름, 소유자 이름은 전송되지 않습니다.
  • 각 제공처가 요청 기록을 어떻게 다루는지는 해당 제공처의 개인정보처리방침을 따릅니다.

5. 제3자 제공, 광고, 분석 도구

개발자는 사용자의 정보를 보유하지 않으므로 제3자에게 제공하거나 판매하지 않습니다. 앱에는 광고와 사용 행태 분석 도구가 없습니다.

6. 파일 내보내기와 가져오기

사용자가 설정에서 "내보내기"를 실행하면 앱 데이터가 JSON 파일로 사용자가 고른 위치에 저장됩니다. 이 파일은 암호화되지 않으며 자산 내역(보유 수량과 금액)이 그대로 들어 있으므로 안전한 곳에 보관해야 합니다. 앱 잠금 설정(PIN 해시값 포함)과 공공데이터포털 인증키는 이 파일에 넣지 않습니다. 파일을 가져올 때에도 앱 잠금 설정은 바뀌지 않고 기기에 있던 설정이 그대로 유지됩니다. 앱은 이 파일을 어디에도 전송하지 않습니다.

7. 알림

리밸런싱일, 목표 비중 이탈, 예적금 만기 알림은 기기 안에서 만들어집니다. 알림을 위해 외부 서버와 통신하지 않습니다.

8. 보관 기간과 삭제

정보는 사용자가 지울 때까지 기기에 보관됩니다. 다음 방법으로 삭제할 수 있습니다.

  • 앱의 설정 → "정보 초기화"
  • 기기 설정에서 앱 데이터 삭제 또는 앱 삭제

개발자는 사용자의 정보를 가지고 있지 않으므로 개발자에게 삭제를 요청할 대상 정보가 없습니다.

9. 권한

  • 인터넷: 시세 조회와 종목 검색
  • 알림: 리밸런싱·만기 알림 표시(사용자가 허용한 경우)
  • 생체 인증: 앱 잠금 해제(사용자가 켠 경우)

앱이 사용하는 라이브러리(백그라운드 작업 예약)가 네트워크 상태 확인, 기기 재시작 후 작업 재예약 등에 필요한 권한을 함께 선언합니다. 이 권한으로 개인정보를 수집하지 않습니다.

10. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 수집하지 않습니다.

Asset Manager (자산관리) Privacy Policy

Effective date: 2026-11-16

1. Summary

  • This app has no server operated by the developer. The developer does not collect or receive your information.
  • The asset information you enter is stored only on your device.
  • To fetch prices and search for instruments, ticker codes and search terms are sent to third-party market data providers. Quantities, amounts and account details are never sent.
  • There are no ads, no analytics tools and no sign-in.

2. Information collected by the developer

None. The app does not send any information to the developer.

3. Information stored only on your device

The following is entered by you or calculated by the app and stored in the app's private storage. It is not transmitted.

  • Owner labels, holdings, quantities and target weights per account, deposits and bonds, asset snapshots, financial goals, and your investment policy settings
  • The last fetched exchange rates, prices and market indicators, and a cache of historical prices
  • App settings (theme, display mode, notifications, refresh interval, etc.)
  • A hash of your PIN if app lock is enabled (the PIN itself is not stored)
  • Your Korean Public Data Portal API key, if one is set in your data

The storage location is private to the app and cannot be read by other apps. The file is not separately encrypted. It is excluded from device cloud backup.

Biometric authentication (fingerprint or face) is handled by the operating system. The app never receives or stores biometric data, only whether authentication succeeded.

4. Information sent off your device

When fetching prices or searching for instruments, the app sends requests directly to the providers below. All requests use HTTPS.

ProviderWhat is sentWhen
Naver Finance (m.stock.naver.com, api.stock.naver.com, ac.finance.naver.com)Korean ticker codes, search termsPrice refresh, historical prices, instrument search
Yahoo Finance (query1.finance.yahoo.com)Overseas tickers, FX and index symbols, search termsPrice, FX and index refresh, historical prices, instrument search
Korean Public Data Portal (apis.data.go.kr)Korean ticker codes and your Public Data Portal API keyClosing price lookup when an API key is set
  • As with any internet request, your IP address is visible to each provider.
  • Requests include a generic browser-style User-Agent string. No device identifier, advertising ID or account information is included.
  • Quantities, valuations, account names and owner labels are never sent.
  • How each provider handles request logs is governed by that provider's own privacy policy.

5. Sharing, ads and analytics

The developer holds none of your information and therefore does not share or sell it. The app contains no ads and no usage analytics.

6. Export and import

When you run "Export" in Settings, your app data is saved as a JSON file to a location you choose. The file is not encrypted and contains your asset records (quantities and amounts) as they are, so keep it somewhere safe. App lock settings (including the PIN hash) and the Public Data Portal API key are not written to this file, and importing a file does not change the app lock settings on your device. The app does not send this file anywhere.

7. Notifications

Rebalancing, target-band and deposit maturity notifications are generated on the device. No external server is contacted for notifications.

8. Retention and deletion

Information stays on your device until you delete it. You can delete it by:

  • Settings → "Reset data" in the app
  • Clearing the app's data or uninstalling the app in device settings

Because the developer holds none of your information, there is nothing for the developer to delete on request.

9. Permissions

  • Internet: price lookup and instrument search
  • Notifications: rebalancing and maturity alerts (if you allow them)
  • Biometrics: unlocking the app (if you enable it)

A library used for background scheduling also declares permissions needed to check network state and reschedule work after reboot. These are not used to collect personal information.

10. Children

This app is not directed to children and does not collect children's information.

11. Changes

If this policy changes, the new version will be posted on this page with an updated effective date.
